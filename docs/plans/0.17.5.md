## Next (not in 0.17.5)

- Fold ship's menu into fix's `gate_f` and change's `scope_gate` too (fix 5 → 4, change 4 → 3): those gates have list
  choices, which keep no `<id>_answer` with the payload yet.
- The API (`FlowService.start`) and MCP `keel_start_flow` do not compare the cap with the estimate; only the web's
  Start a flow does.
- The web has no form for skip choices (payload `skip`); they go through the MCP or the API. A checklist on the spec
  gate would make the folded menus usable from the Flow page.
- Out-of-turns continuation for opencode (no resumable session in keel yet) and for API-mode agents.
- The investigator round runs on the default model; a setting for its model (and for the ladder's rounds) would help.
- `skip` moves a stuck criterion to the end; it comes back as the last one. A "park" status (left out of this flow,
  listed in the PR body) would end the flow without it.
